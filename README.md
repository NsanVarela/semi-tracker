# Semi-Marathon Tracker

App de suivi pour ta préparation semi-marathon (16 semaines).

## Déployer sur Vercel (GRATUIT)

### Option 1 : Avec GitHub (Recommandé - Auto-deploy)

1. **Crée un compte GitHub** (si tu n'en as pas)
   - Va sur https://github.com/signup

2. **Crée un nouveau repository**
   - Clique "New" → nom: `semi-tracker`
   - Upload tous les fichiers (ou clone ce dossier)

3. **Déploie sur Vercel**
   - Va sur https://vercel.com
   - Clique "Sign Up" → connecte-toi avec GitHub
   - Clique "Add New" → "Project"
   - Sélectionne ton repo `semi-tracker`
   - Clique "Deploy"
   - **C'est fait !** Tu reçois une URL genre: `semi-tracker-abc123.vercel.app`

### Option 2 : Sans GitHub (Upload direct)

1. **Crée un compte Vercel**
   - Va sur https://vercel.com
   - Clique "Sign Up"

2. **Upload les fichiers**
   - Dans Vercel, "Add New" → "Project"
   - "Upload Files" ou "From Git"
   - Upload ce dossier

3. **Deploy**
   - Clique "Deploy"
   - Tu reçois une URL

## Après le déploiement

- **URL de l'app** : `https://ton-app-name.vercel.app`
- **Accès** : Ouvre l'URL depuis n'importe quel appareil (téléphone, ordi, etc.)
- **Données** : Sont sauvegardées automatiquement dans ton navigateur
- **Offline** : Fonctionne sans internet après la 1ère charge
